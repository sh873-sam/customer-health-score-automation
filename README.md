# Customer Health Score Automation
An n8n workflow that automates customer health scoring for TAM and CS teams.

## What it does
- Runs every weekday at 8AM
- Scores accounts 0-100 using usage metrics, NPS, ticket volume & adoption rates
- Routes high/critical risk accounts to Slack alerts and Asana tasks
- Logs all accounts to a Google Sheets dashboard

## Built with
n8n · JavaScript · Google Sheets · Slack · Asana
